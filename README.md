# Restaurant-Management-System
Restaurant Management System — Java

An academic group project focused on designing and developing a restaurant management system from scratch.

The system was designed to manage menu items, including main dishes and desserts, and handle customer orders through a graphical user interface (GUI).

Key Concepts & Implementation:

* Object-Oriented Programming (OOP).
* Inheritance and Abstract Classes.
* Interfaces.
* Custom Exception Handling.
* Linked List Data Structure.
* Graphical User Interface (GUI).
* Menu and Order Management.

Technologies: Java

Project Type: Academic Group Project
